# ひかりの伝説 〜 Legend of Light 〜

ドラクエ風の 3D RPG（スマホ向け・ブラウザで動作）。フィールド・建物・木・キャラクター・モンスターはすべて **Blender** で作り、**Three.js（WebGL）** で描画しています。名前・ストーリー・音楽はすべてオリジナルです。

## 遊び方

```bash
npm install
```

```bash
npm run dev
```

- **PC**：表示された `http://localhost:5173` を開く
- **スマホ**：PC と同じ Wi-Fi につないで `http://<PCのIPアドレス>:5173` を開く（例 `http://192.168.0.101:5173`）。
  ブラウザのメニューから「ホーム画面に追加」すると全画面のアプリとして遊べます。

| 操作 | スマホ | PC |
|---|---|---|
| 移動 | 画面左側をドラッグ（仮想スティック。大きく倒すと走る） | WASD / 矢印キー |
| カメラ | 画面右側をドラッグ、2本指でズーム | マウスドラッグ、ホイール、Q/E |
| はなす・しらべる・決定 | A ボタン | Enter / Space / Z |
| キャンセル・メニュー | B / MENU ボタン | Esc / X / M |

ゲームパッドにも対応しています。

## ゲーム内容

- アルセリア城の王さまに会い、北の山奥「まおうの塔」の魔竜ヴァルザードを倒すのが目的
- フィールドを歩くモンスターに触れると、その場で 3D の戦闘に（たたかう／じゅもん／どうぐ／ぼうぎょ／にげる）
- レベルアップで 7 種類の呪文を習得、ミナトの村の店で装備を買い、宿屋で回復
- 昼夜の移り変わり（夜はゴーストが出る・窓や街灯がともる・ホタル）
- セーブは王さまに話す／宿屋に泊まる（アプリを閉じたときも自動で記録）
- 画質は「メニュー → せってい → がしつ」で 最高／高／軽量 を切り替え（スマホは「高」で開始）

## Blender での編集

`blender/world.blend` を Blender で開くと、`World`・`Props`・`Characters` の 3 シーンがあります。

- **World**：地形（`Terrain`）・建物・木の配置（`Scatter` のコレクションインスタンス）・当たり判定（`COL_*`）・会話相手やイベントの位置（`MK_*`）
- **Props**：木・岩・茂みの元モデル（`_LOD` は遠景用）
- **Characters**：勇者・NPC（骨格とアニメーション付き）・モンスター

地形をスカルプトしたり、建物や木・マーカーを動かしたら保存して、次を実行するとゲームに反映されます。

```bash
npm run export
```

スクリプトから世界を**作り直す**場合（`world.blend` は上書きされるので注意）：

```bash
npm run rebuild
```

| スクリプト | 内容 |
|---|---|
| `blender/build_world.py` | 地形（高さ・色）、城・村・塔、街灯、木の配置 |
| `blender/build_characters.py` | 人型キャラ（メタボール造形・髪・顔・服・装備・骨格・9 種のアニメ） |
| `blender/build_monsters.py` | モンスター 6 種（メタボール造形） |
| `blender/export_game.py` | `public/assets/*.glb` と `world.json`（高さマップ・配置・当たり判定）を書き出し |

## 公開・アプリ化

```bash
npm run build
```

`dist/` を静的ホスティング（Netlify・Vercel・GitHub Pages など）に置けば、どのスマホからも URL で遊べます。
App Store / Google Play 向けのネイティブアプリにする場合は、`dist/` を [Capacitor](https://capacitorjs.com/) で包むのが近道です。

## 構成

```
src/
  main.js            ゲーム全体の流れ（タイトル・フィールド・戦闘・エンディング）
  core/renderer.js   レンダラーとポストエフェクト（MSAA・ブルーム・色調補正）
  world/             地形・空と昼夜・水面・草と花・木・建物の質感・煙と街灯
  actors/            キャラクターとモンスター（アニメーション）
  game/              フィールド操作・戦闘・メニュー・データ・セーブ
  ui/                ドラクエ風ウィンドウ・HUD・ミニマップ
  audio.js           オリジナル BGM と効果音（WebAudio シンセ）
blender/             Blender の生成・書き出しスクリプトと world.blend
public/assets/       ゲームが読み込むモデルとデータ
```

開発用：URL に `?dev` を付けるとタイトルを飛ばします（`&t=0.9` で夜、`&x=..&z=..` で位置、`&battle` で戦闘、`&boss` でボス戦、`&lv=10` でレベル）。
